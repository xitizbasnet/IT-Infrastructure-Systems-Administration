# 10. SCCM / Microsoft Endpoint Configuration Manager

> 📘 **Document Type:** Enterprise Endpoint Management & Software Deployment Lab Guide
> 
> 🏢 **Department:** Information Technology (IT)
> 
> 🎯 **Objective:** Deploy Microsoft Endpoint Configuration Manager (SCCM), manage enterprise software distribution, client deployment, and centralized patch management.

---

# Objective

Deploy SCCM, distribute software and manage patching at enterprise scale.

---

# 10.1 SCCM Primary Site Installation (Overview)

---

## Step 1: Prerequisites

🧱 Prepare infrastructure requirements:

* Windows Server (2019+)
* SQL Server 2019+
* Windows ADK + WinPE Add-on

---

### Active Directory Preparation

📌 Extend AD schema:

```text id="sccm_001"
extadsch.exe
```

---

### Create System Management Container

📍 In Active Directory:

* Create **System Management** container
* Delegate permissions:

  * Site Server → Full Control

📌 Purpose:

* Allows SCCM to publish site data into Active Directory

---

## Step 2: Run SCCM Setup

💿 Launch installation:

📍 Mount SCCM ISO:

```text id="sccm_002"
splash.hta → Install
```

---

### Installation Configuration:

* Select: **Primary Site**
* Site Code: `PS1`
* Site Name: Custom organization name
* Define installation paths

---

### Prerequisite Check:

* Run validation checks
* Resolve all warnings/errors
* Proceed with installation

📌 Purpose:

* Establishes SCCM primary management site

---

# 10.2 Client Deployment

---

## Step 1: Enable Client Push Installation

📡 Configure automatic client deployment:

📍 Navigate:

```text id="sccm_003"
SCCM Console → Administration → Site Configuration → Sites → Client Installation Settings
```

---

### Enable:

* Client Push Installation
* Specify installation account credentials

---

### Deploy Client:

📍 Navigate:

```text id="sccm_004"
Devices → Right-click Device → Install Client
```

📌 Purpose:

* Installs SCCM agent on managed endpoints

---

# 10.3 Software Distribution

---

## Step 1: Create Application

📦 Define application package:

📍 Navigate:

```text id="sccm_005"
Software Library → Application Management → Applications → Create Application
```

---

### Application Options:

* Auto-detect MSI installer OR
* Manually define deployment type

📌 Purpose:

* Standardizes software deployment across enterprise devices

---

## Step 2: Deploy Application

🚀 Deploy software to endpoints:

* Right-click Application → Deploy
* Select Collection

---

### Deployment Types:

| Type      | Description               |
| --------- | ------------------------- |
| Required  | Forced installation       |
| Available | Self-service installation |

📌 Purpose:

* Controls software availability and enforcement

---

# 10.4 Software Update Management (SUP)

---

## Step 1: Configure Software Update Point

🔄 Enable patch management role:

📍 Navigate:

```text id="sccm_006"
Administration → Site Configuration → Servers → Site System Roles → Add Software Update Point
```

---

### Configuration:

* Sync with Microsoft Update
* Select products:

  * Windows 10/11
  * Microsoft Office 365

📌 Purpose:

* Enables centralized patch synchronization

---

## Step 2: Deploy Patch Tuesday Updates

🛡️ Manage monthly updates:

📍 Navigate:

```text id="sccm_007"
Software Library → Software Updates → All Software Updates
```

---

### Process:

* Filter current month updates
* Download updates
* Deploy to target collection

---

### Maintenance Window Configuration:

* Example:

  * Saturday 2:00 AM – 5:00 AM

📌 Purpose:

* Prevents disruption during business hours

---
