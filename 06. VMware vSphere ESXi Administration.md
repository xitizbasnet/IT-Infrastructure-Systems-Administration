---

# 6.1 ESXi Host Initial Setup

---

## Step 1: Access ESXi Host Client

🌐 Connect to ESXi management interface:

```text id="esxi001"
https://<ESXi-IP>/ui
```

### Login:

* Username: `root`
* Password: `<configured_password>`

---

### Configure Management Network

📍 Navigate:

* Networking → VMkernel NIC

### Set:

* Management IP Address
* DNS Servers
* Default Gateway

📌 Purpose:

* Enables remote administration of ESXi host
* Ensures network connectivity for management services

---

## Step 2: Configure NTP

⏱️ Synchronize system time:

📍 Navigate:

```text id="esxi002"
Manage → System → Time & Date → NTP Settings
```

### Add NTP Server:

* Example:

  * `pool.ntp.org`

📌 Purpose:

* Ensures accurate time synchronization
* Critical for logs, authentication, and clustering

---

# 6.2 vCenter Server Deployment

---

## Step 1: Deploy VCSA (vCenter Server Appliance)

📦 Launch vCenter deployment:

* Mount VCSA ISO
* Run installer on:

  * Windows / Linux / Mac

---

### Stage 1: Deployment

* Deploy OVF template to ESXi host
* Assign compute, storage, and network settings

---

### Stage 2: Configuration

* Set SSO domain:

  * `vsphere.local`
* Configure administrator password

📌 Purpose:

* Centralized management of ESXi hosts and clusters

---

## Step 2: Add ESXi Hosts to vCenter

🌐 Open vSphere Client:

📍 Navigate:

```text id="vc001"
Hosts & Clusters → Add Host
```

---

### Configuration Steps:

* Enter ESXi hostname/IP
* Provide root credentials
* Accept SSL thumbprint

📌 Purpose:

* Integrates ESXi host into centralized vCenter management

---

# 6.3 VM Templates & Cloning

---

## Step 1: Convert VM to Template

📦 Create reusable VM image:

* Power off VM
* Right-click VM
* Select:

```text id="vc_template_001"
Template → Convert to Template
```

📌 Purpose:

* Standardizes deployments
* Reduces manual configuration effort

---

## Step 2: Deploy VM from Template

🚀 Create new VM:

* Right-click template
* Select:

  * **New VM from this Template**

---

### Customization Specification

Configure automatically:

* Hostname
* IP Address
* Domain Join settings

📌 Purpose:

* Enables automated provisioning of standardized VMs

---

# 6.4 vSphere HA & DRS

---

## Step 1: Enable HA (High Availability)

🛡️ Configure cluster failover protection:

📍 Navigate:

```text id="ha001"
Cluster → Configure → vSphere Availability → Edit
```

### Enable:

* vSphere HA

---

### Admission Control Policy:

* Reserve **25% cluster resources** for failover

📌 Purpose:

* Ensures VM restart capability during host failure

---

## Step 2: Enable DRS (Distributed Resource Scheduler)

⚖️ Configure workload balancing:

📍 Navigate:

```text id="drs001"
Cluster → Configure → vSphere DRS → Edit
```

### Settings:

* Automation Level: **Fully Automated (Level 3 / Aggressive)**

📌 Purpose:

* Automatically balances VM workloads across hosts
* Improves performance and resource utilization

# BEST PRACTICE TIPS

---

## 🧩 VMware Tools Installation

* Install **VMware Tools** on every VM

📌 Benefits:

* Improved performance
* Better hardware compatibility
* Enhanced guest OS management

---

## 🧱 Host Profile Consistency

* Use ESXi Host Profiles to:

  * Standardize configurations
  * Ensure compliance across hosts

---

## 🔄 Disaster Recovery Strategy

* Enable:

  * vSphere Replication OR Zerto

📌 Purpose:

* Provides VM-level disaster recovery
* Enables rapid failover to secondary site

---

## 📚 Content Library Usage

* Store centrally:

  * ISOs
  * Templates
  * OVF packages

📌 Purpose:

* Simplifies large-scale deployments
* Ensures version consistency

---

## 🔐 Certificate Management

* Regularly monitor vCenter certificates
* Renew before expiration

📌 Purpose:

* Prevents service disruption
* Maintains secure communications
