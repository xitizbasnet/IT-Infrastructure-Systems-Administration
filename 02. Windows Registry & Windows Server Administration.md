# 2.1 Windows Registry Essentials

---

## Step 1: Open Registry Editor

🧭 Launch Registry Editor:

```text id="reg001"
Run → regedit → Yes (UAC prompt)
```

---

## Step 2: Key Registry Hives Overview

🗂️ Understanding core registry hives:

| Registry Hive                            | Purpose                                   |
| ---------------------------------------- | ----------------------------------------- |
| `HKLM\SOFTWARE`                          | Machine-wide application settings         |
| `HKCU\SOFTWARE`                          | Per-user configuration settings           |
| `HKLM\SYSTEM\CurrentControlSet\Services` | Service configuration settings            |
| `HKLM\SECURITY`                          | Local security policy (restricted access) |

---

## Step 3: Create a Registry Backup

💾 Always back up before making changes:

📍 Navigate:

* File → Export → All

### Save file as:

```text id="reg_backup"
backup_YYYYMMDD.reg
```

⚠️ Purpose:

* Enables rollback in case of misconfiguration

---

## Step 4: Common Administrative Registry Edits

---

### 🚫 Disable USB Storage

📍 Path:

```text id="usb_disable"
HKLM\SYSTEM\CurrentControlSet\Services\USBSTOR
```

### Modify Value:

* `Start = 4`

📌 Effect:

* Disables USB storage devices

---

### ⚠️ Set Legal Logon Banner

📍 Path:

```text id="legal_banner"
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
```

### Add Values:

* `LegalNoticeCaption` (REG_SZ):

  * `Authorised Users Only`

* `LegalNoticeText` (REG_SZ):

  * `Unauthorised access is prohibited.`

📌 Effect:

* Displays warning message at login

---

## Step 5: Remote Registry Editing

🌐 Execute registry change on remote system:

```powershell id="reg_remote"
reg add \\RemotePC\HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate /v DisableWindowsUpdateAccess /t REG_DWORD /d 0 /f
```

📌 Purpose:

* Enables controlled remote registry modification

# 2.2 Windows Server Core Administration Tasks

---

## Step 1: Disk Management

🖥️ Access disk utilities:

📍 Navigate:

```text id="disk_mgmt"
Server Manager → Tools → Disk Management
```

### Tasks:

* Initialise new disks
* Create partitions
* Format volumes

---

## Step 2: Event Viewer

📊 Monitor system logs:

📍 Navigate:

```text id="event_viewer"
Server Manager → Tools → Event Viewer
```

### Log Categories:

* Windows Logs:

  * System
  * Application
  * Security

📌 Purpose:

* Troubleshooting
* Security auditing
* System diagnostics

---

## Step 3: Performance Monitoring

📈 Launch Performance Monitor:

```text id="perfmon"
PerfMon → Data Collector Sets → System Performance → Start
```

📌 Purpose:

* Monitor system performance metrics
* Identify bottlenecks and resource usage

---

## Step 4: PowerShell Administrative Commands

💻 Common PowerShell operations:

---

### View Recent System Errors

```powershell id="ps1"
Get-EventLog -LogName System -Newest 50 -EntryType Error
```

---

### List Stopped Services

```powershell id="ps2"
Get-Service | Where-Object {$_.Status -eq 'Stopped'}
```

---

### Restart Print Spooler Service

```powershell id="ps3"
Restart-Service -Name 'Spooler'
```

---

### Top CPU-Consuming Processes

```powershell id="ps4"
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10
```

# BEST PRACTICE TIPS

---

## 💾 Registry Safety

* Always export registry before changes
* Maintain versioned backups for rollback

---

## 🧠 Prefer Group Policy Over Registry Edits

* Use **Group Policy Preferences** instead of direct registry modifications when possible
* Reduces human error and improves scalability

---

## 🔐 Restrict Registry Access

* Disable `regedit` for standard users via Group Policy
* Prevents unauthorized system modifications

---

## 💾 Backup Strategy

* Enable **Windows Server Backup role**
* Perform:

  * Daily system-state backups

📌 Purpose:

* Fast recovery from system corruption

---

## 📊 Event Log Management

* Increase log size to at least:

  * **256 MB minimum**

* Forward logs to SIEM system for:

  * Centralized monitoring
  * Security correlation
  * Incident response
