# 11.1 Microsoft 365 Tenant Initial Setup

---

## Step 1: Add & Verify Custom Domain

🌐 Configure domain identity in Microsoft 365:

📍 Navigate:

```text id="m365_001"
Microsoft 365 Admin Centre → Settings → Domains → Add domain
```

---

### DNS Verification & Records

To validate and enable mail services, configure the following DNS records at your domain provider:

* TXT record (domain verification)
* MX record (mail routing)
* CNAME record (Autodiscover)
* SPF record (anti-spoofing)
* DKIM record (email authentication)

📌 Purpose:

* Establishes domain trust and enables secure email delivery

---

## Step 2: Assign Licences

💳 Allocate Microsoft 365 licenses:

📍 Navigate:

```text id="m365_002"
Admin Centre → Billing → Licences
```

### Assignment Options:

* Individual users
* Group-based licensing

📌 Purpose:

* Enables access to Exchange, Teams, OneDrive, and other M365 services

# 11.2 Exchange Online — Shared Mailbox & Distribution List

---

## Step 1: Create Shared Mailbox

📬 Configure shared organizational mailbox:

📍 Navigate:

```text id="exo_001"
Exchange Admin Centre → Recipients → Mailboxes → Add shared mailbox
```

---

### Configuration:

* Add members
* Assign permissions:

  * Send As
  * Full Access

📌 Purpose:

* Enables multiple users to manage a common mailbox (e.g., [support@company.com](mailto:support@company.com))

---

## Step 2: Create Distribution Group

📨 Create email distribution list:

📍 Navigate:

```text id="exo_002"
Exchange Admin Centre → Recipients → Groups → Add distribution group
```

---

### Configuration:

* Alias
* Group owner
* Members
* Delivery restrictions

📌 Purpose:

* Enables bulk email communication to defined user groups

---

# 11.3 Outlook — Manual IMAP / POP3 Configuration

---

## Step 1: Configure IMAP in Outlook

📧 Add IMAP email account:

📍 Navigate:

```text id="outlook_001"
File → Add Account → Advanced setup → IMAP
```

---

### IMAP Settings:

| Setting         | Value                         |
| --------------- | ----------------------------- |
| Incoming Server | imap.yourdomain.com           |
| Port            | 993                           |
| Encryption      | SSL                           |
| Outgoing Server | smtp.yourdomain.com           |
| Port            | 587                           |
| Encryption      | TLS                           |
| Authentication  | Full email address + password |

📌 Purpose:

* Synchronizes emails across multiple devices

---

## Step 2: Configure POP3 in Outlook

📥 Configure POP email retrieval:

📍 Navigate:

```text id="outlook_002"
File → Add Account → Advanced setup → POP
```

---

### POP3 Settings:

| Setting         | Value               |
| --------------- | ------------------- |
| Incoming Server | pop.yourdomain.com  |
| Port            | 995                 |
| Encryption      | SSL                 |
| Outgoing Server | smtp.yourdomain.com |
| Port            | 587                 |
| Encryption      | TLS                 |

---

### Recommended Setting:

* Leave messages on server for **30 days**

📌 Purpose:

* Ensures email availability across devices while avoiding data loss

# 11.4 Microsoft 365 SMTP Relay (Devices & Applications)

---

## Step 1: Enable SMTP Authentication

⚙️ Enable authenticated SMTP:

```powershell id="smtp_001"
Set-CASMailbox -Identity scanner@corp.com -SmtpClientAuthenticationDisabled $false
```

📌 Purpose:

* Allows secure SMTP-based email sending from applications and devices

---

## Step 2: Direct Send (No Authentication)

📤 Configure devices like printers or scanners:

### SMTP Settings:

| Setting        | Value                                      |
| -------------- | ------------------------------------------ |
| SMTP Server    | yourtenant-com.mail.protection.outlook.com |
| Port           | 25                                         |
| Encryption     | None                                       |
| Authentication | Not required                               |

---

📌 Requirements:

* Device must originate from allowed public IPs
* Must belong to accepted domain

📌 Purpose:

* Enables secure internal device email sending without credentials

# BEST PRACTICE TIPS

---

## 🔐 Email Security Hardening

* Enable:

  * DKIM
  * DMARC
  * SPF

📌 Purpose:

* Prevents email spoofing and phishing attacks

---

## 🚫 Block Legacy Authentication

* Use Conditional Access to disable:

  * IMAP (legacy)
  * POP3 (legacy)

📌 Purpose:

* Reduces credential theft risk

---

## 🔄 Autodiscover Configuration

* Configure Autodiscover SRV records

📌 Purpose:

* Enables automatic Outlook configuration

---

## 📊 Mail Flow Monitoring

* Use:

  * Exchange Admin Centre → Message Trace

📌 Purpose:

* Tracks email delivery and troubleshooting

---

## 🔐 Multi-Factor Authentication (MFA)

* Enable MFA for all users
* Prefer passwordless authentication where possible

📌 Purpose:

* Strengthens identity security and reduces account compromise risk
