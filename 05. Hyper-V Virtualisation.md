# 05. Hyper-V Virtualisation

> 📘 **Document Type:** Virtualisation Infrastructure Lab Guide
> 
> 🏢 **Department:** Information Technology (IT)
> 
> 🎯 **Objective:** Install, configure, and manage Microsoft Hyper-V virtual machines, virtual networking, checkpoints, and live migration.

---

# Objective

Install, configure, and manage Hyper-V virtual machines and networking.

---

# 5.1 Enable Hyper-V Role

---

## Step 1: Enable via Server Manager

🧩 Install Hyper-V role using GUI:

📍 Navigate:

```text id="hv001"
Add Roles & Features → Hyper-V → Install → Reboot
```

### Process Includes:

* Select Hyper-V role
* Accept all required sub-features
* Complete installation wizard
* Restart server

---

## Step 2: Enable via PowerShell

⚡ Alternative installation method:

```powershell id="hv002"
Install-WindowsFeature -Name Hyper-V -IncludeManagementTools -Restart
```

📌 Purpose:

* Installs Hyper-V role and management tools
* Automatically reboots system after installation

---

# 5.2 Create a Virtual Switch

---

## Step 1: Virtual Switch Manager

🌐 Open Hyper-V Manager:

📍 Navigate:

```text id="hv003"
Virtual Switch Manager → New → External
```

---

### Configuration:

| Setting      | Value                         |
| ------------ | ----------------------------- |
| Switch Type  | External                      |
| Physical NIC | Select active network adapter |
| Name         | ExternalSwitch                |

📌 Purpose:

* Allows VMs to access LAN and Internet
* Bridges virtual and physical network

---

# 5.3 Create a Virtual Machine

---

## Step 1: New Virtual Machine Wizard

🖥️ Create VM in Hyper-V Manager:

📍 Navigate:

```text id="hv004"
Hyper-V Manager → New → Virtual Machine
```

---

### VM Configuration:

| Setting            | Value                              |
| ------------------ | ---------------------------------- |
| Name               | Custom VM name                     |
| Generation         | Generation 2 (UEFI)                |
| RAM                | Minimum 2 GB (Dynamic recommended) |
| Network            | ExternalSwitch                     |
| Storage            | New VHD (e.g., 60 GB)              |
| Installation Media | ISO file                           |

---

## Step 2: VM Advanced Settings

⚙️ Optimize VM configuration:

---

### Secure Boot Configuration

* Disable Secure Boot for Linux guests
  OR
* Set template to:

```text id="hv005"
Microsoft UEFI Certificate Authority
```

---

### Integration Services

* Enable:

  * Guest Services

📌 Purpose:

* Enhances VM host interaction and file transfer support

---

### CPU Configuration

* Set processor count based on workload
* Enable:

  * NUMA spanning (for large VMs)

---

# 5.4 Checkpoints & Live Migration

---

## Step 1: Create Checkpoint

📸 Create VM snapshot for rollback:

```powershell id="hv006"
Checkpoint-VM -Name 'Server01' -SnapshotName "Pre-Patch-$(Get-Date -f yyyyMMdd)"
```

📌 Purpose:

* Captures VM state before changes
* Enables quick recovery

---

## Step 2: Configure Live Migration

🔄 Enable VM mobility between hosts:

### Requirements:

* Both Hyper-V hosts:

  * Must be in same Active Directory domain
  * Must share storage or be configured for migration

---

### Enable Live Migration:

📍 Navigate:

```text id="hv007"
Hyper-V Settings → Live Migrations → Enable
```

### Configuration:

* Enable Live Migration
* Set maximum concurrent migrations

📌 Purpose:

* Allows zero-downtime VM movement between hosts

---

# BEST PRACTICE TIPS

---

## 🧱 Use Generation 2 VMs

* Always use Generation 2 for new workloads
* Benefits:

  * UEFI support
  * Better performance
  * Secure boot capability

---

## 💾 Storage Separation

* Store VHD files on separate disks from OS

📌 Purpose:

* Improves performance
* Reduces I/O bottlenecks

---

## ⚡ Dynamic Memory Usage

* Enable only for:

  * Test environments
  * Desktop workloads

🚫 Avoid for:

* Production databases
* Critical servers

---

## 🧹 Checkpoint Management

* Schedule automatic cleanup of checkpoints
* Prevents:

  * Disk space exhaustion
  * Performance degradation

---

## 🏢 Active Directory Integration

* Join Hyper-V hosts to AD domain
* Enable delegated administration

📌 Purpose:

* Centralized control
* Role-based access management
