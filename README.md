# IT Infrastructure & Systems Administration

📘 Enterprise-Level Practical IT Administration & Infrastructure Engineering Series

---

## 📌 Overview

This repository contains a structured, hands-on IT infrastructure and systems administration curriculum designed to simulate real-world enterprise environments.

It covers core domains including:

* 🪟 Windows Server Administration
* 🐧 Linux System Administration
* 🌐 Networking & IP Architecture
* ☁️ Cloud Platforms (Azure, Microsoft 365)
* 🔐 Identity & Access Management (IAM / PAM / MFA / SSO)
* 🖥️ Virtualization (Hyper-V, VMware)
* 📡 Enterprise Services (Printing, Scanning, Fax)
* 📊 Monitoring & Security Operations
* 💾 Backup & Disaster Recovery Systems

---

## 📂 Content Structure

Each section is organized numerically and designed for progressive learning from foundational systems to advanced enterprise architecture.

---

## 📚 Modules

### 01 — Active Directory, Domain Services & Group Policy

Windows Server domain setup, AD DS, domain controllers, user management, and GPO configuration.

---

### 02 — Windows Server Administration & Registry

System administration, registry configuration, event logs, performance tools, and system hardening.

---

### 03 — Linux Administration & Patching

User management, permissions, services, networking, and OS patch management (Ubuntu / RHEL).

---

### 04 — Authentication Protocols & Federation

LDAP, Kerberos, NTLM, SAML, and OIDC authentication systems and identity federation.

---

### 05 — Hyper-V Virtualization

Virtual machine creation, virtual networking, checkpoints, and Hyper-V management.

---

### 06 — VMware vSphere / ESXi

Enterprise virtualization using ESXi hosts, vCenter, HA/DRS, templates, and VM lifecycle management.

---

### 07 — Azure & Microsoft Entra ID

Cloud resource management, identity services, RBAC, Conditional Access, and virtual machines.

---

### 08 — Networking Fundamentals & Port Configuration

IP addressing, subnetting, firewall rules, and essential network ports and protocols.

---

### 09 — Microsoft Intune & Endpoint Management

Device enrollment, compliance policies, update rings, and modern endpoint management.

---

### 10 — SCCM (Endpoint Configuration Manager)

Software deployment, patch management, application distribution, and enterprise update control.

---

### 11 — Microsoft 365 & Email Systems

Exchange Online, SMTP, IMAP, POP3, Outlook configuration, and mail flow management.

---

### 12 — Identity, Security & Zero Trust Architecture

IAM, PAM, MFA, SSO, Okta integration, Conditional Access, and Microsoft cybersecurity framework.

---

### 13 — Network Printing Configuration

IP-based printer deployment, print servers, driver installation, and GPO-based deployment.

---

### 14 — Scanner & Fax Integration

SMTP scan-to-email, SMB scan-to-folder, and fax configuration on multifunction devices.

---

### 15 — Backup & Disaster Recovery

NAS backups, Veeam, Barracuda, Backblaze, Druva, and enterprise 3-2-1 backup strategy.

---

## 🎯 Key Learning Outcomes

After completing this series, learners will be able to:

* Administer enterprise Windows & Linux systems
* Design secure network architectures
* Implement identity and access management systems
* Manage cloud infrastructure and hybrid environments
* Deploy virtualization platforms at scale
* Configure enterprise email, printing, and scanning systems
* Implement backup and disaster recovery strategies
* Apply security best practices and zero trust principles
