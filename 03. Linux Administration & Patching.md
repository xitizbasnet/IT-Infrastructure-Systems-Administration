# 3.1 Essential Linux Admin Commands

---

## Step 1: User & Group Management

👤 Manage users and groups in Linux.

```bash id="linux_user_001"
useradd -m -s /bin/bash john        # Create user
passwd john                         # Set password
usermod -aG sudo john              # Add user to sudo group
groupadd developers                # Create new group
id john                            # Verify user details
```

---

## Step 2: File Permissions

🔐 Manage file ownership and access permissions.

```bash id="linux_perm_001"
chmod 750 /opt/app                 # rwxr-x---
chown john:developers /opt/app
ls -la /opt/app
```

### Permission Breakdown

| Mode | Meaning                |
| ---- | ---------------------- |
| 7    | Read + Write + Execute |
| 5    | Read + Execute         |
| 0    | No access              |

---

## Step 3: Service Management (systemd)

⚙️ Manage system services using systemd.

```bash id="linux_svc_001"
systemctl status sshd
systemctl enable --now sshd
systemctl restart nginx
```

📜 View service logs:

```bash id="linux_log_001"
journalctl -u sshd -n 50 --no-pager
```

---

## Step 4: Networking Commands

🌐 Network diagnostics and configuration.

```bash id="linux_net_001"
ip addr show
ip route show
ss -tlnp              # Show listening ports
nmcli con show        # Network Manager connections
```

# 3.2 Linux Patching — Ubuntu

---

## Step 1: Update & Upgrade System

📦 Refresh package repositories and apply updates.

```bash id="ubuntu_patch_001"
sudo apt update
sudo apt list --upgradable
sudo apt upgrade -y
sudo apt dist-upgrade -y
sudo reboot
```

---

## Step 2: Enable Automated Patching

🤖 Configure unattended upgrades:

```bash id="ubuntu_patch_002"
sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure --priority=low unattended-upgrades
```

📌 Purpose:

* Automatically installs security updates
* Reduces manual patching workload

---

# 3.3 Linux Patching — RHEL / CentOS / Rocky

---

## Step 1: Check & Apply Updates

📦 Use DNF package manager:

```bash id="rhel_patch_001"
sudo dnf check-update
sudo dnf update -y
sudo dnf update --security -y
sudo reboot
```

📌 Purpose:

* Applies system-wide and security-specific patches

---

## Step 2: View Patch History & Security Updates

📜 Review update history:

```bash id="rhel_patch_002"
sudo dnf history list
```

🔐 View security-related updates:

```bash id="rhel_patch_003"
sudo dnf updateinfo list security
```

# BEST PRACTICE TIPS

---

## 💾 Snapshot Before Patching

* Always create VM snapshots before applying patches in production
* Enables quick rollback in case of failure

---

## 🤖 Use Automation Tools

* Use **Ansible** or **Red Hat Satellite** for:

  * Centralized patch management
  * Large-scale deployments
  * Consistent configuration

---

## ⏱️ Patch Timelines

* Apply security patches within **72 hours**
* Align with **CIS Benchmark recommendations**

---

## 🧪 Patch Testing Workflow

Follow structured environment progression:

* Development → UAT → Production

📌 Purpose:

* Prevent production outages
* Validate compatibility

---

## 💽 Boot Partition Requirement

* Ensure `/boot` partition is at least:

  * **1 GB minimum**

📌 Purpose:

* Prevent kernel update failures

---

## 📊 Patch Compliance Monitoring

Use tools such as:

* Lynis
* OpenSCAP

📌 Purpose:

* Automate security compliance reporting
* Identify system vulnerabilities
