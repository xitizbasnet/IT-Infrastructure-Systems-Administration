# 8.1 Static IP Configuration

---

## Step 1: Windows — GUI Method

🖥️ Configure static IP via Control Panel:

📍 Navigate:

```text id="net_gui_001"
Network & Sharing Centre → Change adapter settings → Adapter → Properties → IPv4
```

### Configure:

* IP Address
* Subnet Mask
* Default Gateway
* DNS Servers

📌 Purpose:

* Manually assigns fixed network identity to host

---

## Step 2: Windows — PowerShell Method

⚡ Configure static IP via CLI:

```powershell id="net_ps_001"
New-NetIPAddress -InterfaceAlias 'Ethernet' -IPAddress 192.168.1.50 -PrefixLength 24 -DefaultGateway 192.168.1.1
```

### Set DNS Servers:

```powershell id="net_ps_002"
Set-DnsClientServerAddress -InterfaceAlias 'Ethernet' -ServerAddresses 192.168.1.10,192.168.1.11
```

📌 Purpose:

* Automates IP configuration for scripting and deployment

---

## Step 3: Linux — nmcli Method

🐧 Configure static network settings:

```bash id="net_linux_001"
nmcli con mod eth0 ipv4.addresses 192.168.1.50/24
nmcli con mod eth0 ipv4.gateway 192.168.1.1
nmcli con mod eth0 ipv4.dns "192.168.1.10 8.8.8.8"
nmcli con mod eth0 ipv4.method manual
nmcli con up eth0
```

📌 Purpose:

* Standard method for managing network interfaces on Linux systems

# 8.2 Windows Firewall Port Rules

---

## Step 1: Open Port via GUI

🧱 Configure inbound firewall rules:

📍 Navigate:

```text id="fw_gui_001"
Windows Firewall → Advanced Settings → Inbound Rules → New Rule → Port
```

📌 Purpose:

* Allows controlled network access to services

---

## Step 2: Open Port via PowerShell

⚡ Create firewall rule programmatically:

```powershell id="fw_ps_001"
New-NetFirewallRule -DisplayName "Allow HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow
```

📌 Purpose:

* Automates firewall rule deployment across systems

# BEST PRACTICE TIPS

---

## 📄 Firewall Rule Documentation

* Always document:

  * Open ports
  * Business justification
  * Owner/service dependency

📌 Purpose:

* Ensures audit compliance and security traceability

---

## 🧱 Network Segmentation

* Use VLANs to isolate:

  * Servers
  * Workstations
  * Printers
  * IoT devices

📌 Purpose:

* Reduces attack surface and broadcast traffic

---

## 🚫 Disable Unused Ports

* Disable unused switch ports
* Apply port security policies

📌 Purpose:

* Prevents unauthorized device access

---

## 🔍 Regular Port Scanning

* Use tools:

  * Nmap
  * Qualys

📌 Purpose:

* Detects exposed or unauthorized services

---

## 🌐 Secure Remote Access

* Never expose RDP (3389) directly to the internet

### Preferred Methods:

* VPN
* Azure Bastion
* Jump Hosts

📌 Purpose:

* Prevents brute-force and ransomware attacks
