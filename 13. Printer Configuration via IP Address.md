# 13. Printer Configuration via IP Address

> 📘 **Document Type:** Network Printing, Print Server Administration & Device Integration Lab Guide
> 
> 🖨️ **Platform:** Windows / Linux (CUPS) / Print Server Environments
> 
> 🏢 **Department:** Information Technology (IT)
> 
> 🎯 **Objective:** Configure and manage network printers using IP-based connectivity on Windows and Linux systems.

---

# Objective

Add, configure and manage network printers on Windows and Linux.

---

# 13.1 Add Printer via IP — Windows

---

## Step 1: Find Printer IP Address

🌐 Identify network printer IP:

### Methods:

* Print a **Configuration Page** from printer control panel
* Check **DHCP server lease table** using printer MAC address

📌 Purpose:

* Ensures correct network identification of printer device

---

## Step 2: Add Printer via Windows Settings

🖨️ Add printer manually using IP address:

📍 Navigate:

```text id="printer_win_001"
Settings → Bluetooth & Devices → Printers & Scanners → Add device
```

---

### Manual Add Option:

* Select: **Add manually**
* Choose: **Add a printer using TCP/IP address**

### Configuration:

| Setting     | Value                             |
| ----------- | --------------------------------- |
| IP Address  | 192.168.1.100                     |
| Port Name   | Auto-generated (IP_192.168.1.100) |
| Protocol    | RAW                               |
| Port        | 9100 (standard)                   |
| Alternative | LPR                               |

📌 Purpose:

* Establishes direct network printing connection

---

## Step 3: Install Printer Driver

🧩 Driver installation:

* Select from Windows driver list OR
* Use **Have Disk** option

📌 Purpose:

* Ensures compatibility between OS and printer hardware

---

## Step 4: Share Printer via Print Server

📡 Enable network sharing:

📍 Navigate:

```text id="printer_win_002"
Printer Properties → Sharing → Share this printer
```

### Configuration:

* Assign share name

---

### Group Policy Deployment (Optional):

📍 Navigate:

```text id="printer_gpo_001"
Computer Configuration → Preferences → Control Panel Settings → Printers
```

📌 Purpose:

* Automates printer deployment across domain devices

---

## Step 5: Test Print

🧪 Validate configuration:

* Right-click printer → Properties
* Select **Print Test Page**

📌 Purpose:

* Confirms successful installation and connectivity

---

# 13.2 Add Printer via IP — Linux (CUPS)

---

## Step 1: Enable CUPS Service

🐧 Start printing service:

```bash id="cups_001"
sudo systemctl enable --now cups
```

### Access Web Interface:

```text id="cups_002"
http://localhost:631
```

📌 Purpose:

* Enables centralized Linux print management system

---

## Step 2: Add Printer via CUPS

🖨️ Configure network printer:

📍 Navigate:

```text id="cups_003"
Administration → Add Printer
```

---

### Configuration:

* Select: **AppSocket / HP JetDirect**
* Device URI:

```text id="cups_004"
socket://192.168.1.100:9100
```

* Select:

  * Manufacturer
  * Model OR upload PPD file

📌 Purpose:

* Enables Linux-based network printing integration

---

# 13.3 Print Server — Windows Server

---

## Step 1: Install Print Server Role

🖥️ Enable print services:

📍 Navigate:

```text id="print_srv_001"
Server Manager → Add Roles → Print and Document Services → Print Server
```

📌 Purpose:

* Enables centralized print management in enterprise environments

---

## Step 2: Add & Share Printer via Print Management

🛠️ Manage printers centrally:

📍 Navigate:

```text id="print_srv_002"
Tools → Print Management → Print Servers → Add Printer
```

---

### Actions:

* Add local or remote printer
* Right-click printer → Share

📌 Purpose:

* Provides centralized control over printing infrastructure

---

# BEST PRACTICE TIPS

---

## 📌 Use Static IP Addresses

* Assign:

  * Static IP OR DHCP Reservation for all printers

📌 Purpose:

* Prevents connectivity loss due to IP changes

---

## 🧾 Deploy via Group Policy

* Use GPO Preferences to map printers automatically

📌 Purpose:

* Reduces manual configuration for end users

---

## 🐧 Use CUPS for Cross-Platform Printing

* Recommended for:

  * Linux + Windows mixed environments

📌 Purpose:

* Ensures compatibility across operating systems

---

## 🔐 Secure Printing Protocols

* Enable:

  * IPP over HTTPS (Port 443 / 631)

📌 Purpose:

* Encrypts print data in transit

---

## 👥 Restrict Printer Access

* Apply permissions to:

  * Users
  * Security groups

📌 Purpose:

* Prevents unauthorized print usage and abuse
