# 9.1 Device Enrolment

---

## Step 1: Auto-Enrolment via Entra ID Join

🔗 Configure automatic MDM enrollment:

📍 Navigate:

```text id="intune_001"
Entra ID → Mobility (MDM & MAM) → Microsoft Intune
```

### Configuration:

* MDM User Scope: **All**

---

### Device Join Process:

📍 On Windows device:

```text id="intune_002"
Settings → Accounts → Access work or school → Connect → Join to Entra ID
```

📌 Purpose:

* Enables centralized device management via Intune

---

## Step 2: Windows Autopilot (Zero-Touch Deployment)

🚀 Automate device provisioning:

---

### Retrieve Device Hardware Hash

```powershell id="autopilot_001"
Install-Script -Name Get-WindowsAutoPilotInfo
Get-WindowsAutoPilotInfo -OutputFile AutopilotHashes.csv
```

---

### Upload to Intune

📍 Navigate:

```text id="autopilot_002"
Intune → Devices → Enrolment → Windows Autopilot → Import
```

---

### Assign Deployment Profile

* Configure OOBE settings:

  * Language
  * Region
  * Enrollment behavior

📌 Purpose:

* Enables zero-touch device provisioning
* Standardizes enterprise device setup

---

# 9.2 Compliance & Configuration Policies

---

## Step 1: Create Compliance Policy

🛡️ Define device compliance requirements:

📍 Navigate:

```text id="intune_003"
Intune → Devices → Compliance → Create Policy → Windows 10/11
```

---

### Policy Settings:

| Requirement        | Configuration |
| ------------------ | ------------- |
| Minimum OS Version | Enforced      |
| BitLocker          | Required      |
| Antivirus          | Required      |

---

### Non-Compliance Actions:

* Mark device as non-compliant after **1 day**
* Send email notification after **3 days**

📌 Purpose:

* Ensures device security posture compliance

---

## Step 2: Configuration Profile — Endpoint Protection

🔐 Apply security hardening policies:

📍 Navigate:

```text id="intune_004"
Intune → Devices → Configuration → Create → Templates → Endpoint Protection
```

---

### Enable Features:

* Microsoft Defender Antivirus
* Windows Firewall
* SmartScreen
* Credential Guard

📌 Purpose:

* Protects endpoints from malware, phishing, and credential theft

---

# 9.3 Windows Update for Business (WUfB) via Intune

---

## Step 1: Create Update Ring

🔄 Configure update deployment strategy:

📍 Navigate:

```text id="intune_005"
Intune → Devices → Update rings for Windows 10 and later → Create
```

---

### Update Ring Configuration

| Ring Type       | Feature Update Deferral | Quality Update Deferral |
| --------------- | ----------------------- | ----------------------- |
| Pilot Ring      | 30 days                 | 7 days                  |
| Production Ring | 60 days                 | 14 days                 |

---

### Assignment:

* Pilot Ring → Pilot Group
* Production Ring → All Devices Group

📌 Purpose:

* Staged rollout reduces update-related disruptions

---

## Step 2: Monitor Patch Compliance

📊 Track update status:

📍 Navigate:

```text id="intune_006"
Intune → Reports → Windows Updates → Feature Update Report
```

📌 Purpose:

* Provides visibility into patch deployment status
* Ensures compliance with update policies
