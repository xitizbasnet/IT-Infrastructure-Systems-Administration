# 14. Scanner Configuration via SMTP & Fax Settings

> 📘 **Document Type:** Multifunction Device (MFD) Configuration, Scan-to-Email, SMB Scanning & Fax Integration Lab Guide
> 
> 🖨️ **Platform:** Network Printers / MFDs / SMTP / SMB / Fax Services
> 
> 🏢 **Department:** Information Technology (IT)
> 
> 🎯 **Objective:** Configure secure scan-to-email via SMTP, scan-to-folder using SMB shares, and enable fax functionality on multifunction devices.

---

# Objective

Enable scan-to-email via SMTP, scan-to-folder, and configure fax.

---

# 14.1 Scan-to-Email via SMTP (Port 587)

---

## Step 1: Configure SMTP on Printer / MFD

🌐 Access device configuration:

📍 Navigate:

```text id="scan_email_001"
Printer Web UI → Network / Email / SMTP Settings
```

📌 Note:

* Menu names may vary depending on manufacturer

---

## Step 2: SMTP Settings — Microsoft 365 / Exchange Online

📧 Configure secure email relay:

| Setting        | Value                                       |
| -------------- | ------------------------------------------- |
| SMTP Server    | smtp.office365.com                          |
| Port           | 587                                         |
| Encryption     | STARTTLS                                    |
| Authentication | Enabled                                     |
| Username       | [scanner@corp.com](mailto:scanner@corp.com) |
| Password       | App Password                                |
| From Address   | [scanner@corp.com](mailto:scanner@corp.com) |

📌 Requirement:

* From address must match authenticated mailbox

📌 Purpose:

* Secure email delivery using Microsoft 365 authentication

---

## Step 3: SMTP Settings — Gmail Relay

📧 Configure Google SMTP:

| Setting        | Value          |
| -------------- | -------------- |
| SMTP Server    | smtp.gmail.com |
| Port           | 587            |
| Encryption     | TLS            |
| Authentication | App Password   |

📍 Generate App Password:

```text id="gmail_001"
Google Account → Security → App Passwords
```

📌 Purpose:

* Enables secure authentication for third-party devices

---

## Step 4: SMTP Settings — Internal Exchange (No Authentication Relay)

🏢 Configure internal mail relay:

| Setting        | Value                           |
| -------------- | ------------------------------- |
| SMTP Server    | your-exchange-server.corp.local |
| Port           | 25                              |
| Authentication | None                            |

---

### Exchange Configuration Requirement:

* Add printer IP to:

  * Receive Connector
  * Anonymous relay whitelist

📌 Purpose:

* Enables internal scanning without credentials

---

## Step 5: Test Scan-to-Email

🧪 Validation:

* Perform test scan from MFD panel
* Verify email delivery in mailbox

📌 Purpose:

* Confirms SMTP configuration is functional

---

# 14.2 Scan-to-Folder (SMB)

---

## Step 1: Create Shared Folder on Server

📂 Configure network scan destination:

```powershell id="scan_smb_001"
New-SmbShare -Name "Scans" -Path "D:\Scans" -FullAccess "CORP\ScannerSvc"
```

📌 Purpose:

* Creates secure shared storage for scanned documents

---

## Step 2: Configure Printer Scan-to-Folder

🖨️ Set SMB destination:

📍 Navigate:

```text id="scan_smb_002"
Printer Web UI → Scan → Scan to Network Folder
```

---

### Configuration:

| Setting        | Value                      |
| -------------- | -------------------------- |
| Path           | \server01\Scans            |
| Protocol       | SMB                        |
| Authentication | ScannerSvc service account |

📌 Purpose:

* Enables direct document scanning into centralized storage

---

# 14.3 Enable Fax (If Hardware Supported)

---

## Step 1: Verify Fax Hardware Availability

📠 Check device capability:

* RJ-11 phone line port OR
* Built-in fax modem support

📌 Purpose:

* Ensures hardware compatibility for fax functionality

---

## Step 2: Configure Windows Fax & Scan

🪟 Enable Windows fax service:

📍 Navigate:

```text id="fax_001"
Start → Windows Fax and Scan → Tools → Fax Accounts → Add
```

---

### Configuration:

* Connect to fax modem
* Set line configuration
* Define sender information

📌 Purpose:

* Enables fax sending/receiving via Windows services

---

## Step 3: Printer Fax Configuration

🖨️ Configure fax settings in MFD:

📍 Navigate:

```text id="fax_002"
Printer Web UI → Fax Settings
```

---

### Configuration:

| Setting             | Value                      |
| ------------------- | -------------------------- |
| Line Type           | PSTN or FoIP               |
| Fax Number          | DDI number                 |
| ECM                 | Enabled                    |
| Junk Fax Protection | Enabled                    |
| Resolution          | Fine (200 DPI recommended) |

📌 Purpose:

* Ensures reliable and high-quality fax transmission

---

## Step 4: Fax-to-Email (T.38 / VoIP)

📧 Configure digital fax delivery:

* Configure SMTP relay on MFD
* Incoming faxes delivered as PDF attachments

📌 Purpose:

* Enables digital archiving and eliminates physical fax dependency

---

# BEST PRACTICE TIPS

---

## 🔐 Use Dedicated Service Accounts

* Always use:

  * Scanner service account
* Never use admin credentials

📌 Purpose:

* Reduces security risk from credential exposure

---

## 🔒 Prefer Secure SMTP (Port 587)

* Use:

  * STARTTLS (587)
* Avoid:

  * Port 25 for external authentication

📌 Purpose:

* Ensures encrypted email transmission

---

## 📧 Email Authentication Security

* Enable:

  * SPF
  * DKIM

📌 Purpose:

* Prevents scan-to-email spoofing and spam filtering issues

---

## 📂 Secure Scan Storage

* Store scans in:

  * Access-controlled SMB shares
* Avoid:

  * Public or open folders

📌 Purpose:

* Protects sensitive scanned documents

---

## 🧪 Fax Validation Testing

* Test fax using:

  * Known verified number
* Ensure:

  * ECM enabled

📌 Purpose:

* Reduces transmission errors and improves reliability

---

## 📄 Prefer Fax-to-Email

* Use digital fax delivery instead of physical fax lines

📌 Purpose:

* Improves:

  * Auditability
  * Archiving
  * Efficiency
